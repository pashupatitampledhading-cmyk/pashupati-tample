# पशुपति मन्दिर धादिङ वेबसाइट

## समावेश गरिएका सामग्री
- `index.html` — वेबसाइटको मुख्य पृष्ठ
- `images/temple.jpg` — तपाईंले पठाउनुभएको मन्दिरको फोटो
- `audio/pashupati-bhajan.mp3` — भजन अडियो
- `audio/shiva-aarti.m4a` — आरती अडियो
- `videos/shiva-bhajan-video.mp4` — तपाईंले पठाउनुभएको शिव भजन भिडियो

## GitHub Pages मा राख्ने तरिका
1. ZIP extract गर्नुहोस्।
2. GitHub मा `pashupati-temple-dhading` repository खोल्नुहोस्।
3. ZIP भित्रका `index.html`, `images`, `audio`, `videos` लाई repository को मुख्य (root) भागमा upload गर्नुहोस्।
4. पुरानो `index.html` replace गरेर commit गर्नुहोस्।
5. केही मिनेटपछि वेबसाइट refresh गर्नुहोस्।

सबै फोल्डर र फाइलको नाम जस्ताको तस्तै राख्नुहोस्, नत्र फोटो/अडियो/भिडियो नदेखिन वा नबज्न सक्छ।
